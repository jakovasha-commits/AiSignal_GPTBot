# Trading AI Telegram Bot

## Обзор
Это Telegram-бот, который сочетает нейросетевой движок (OpenAI + TradingView) с набором из более 15 технических индикаторов, чтобы выдавать понятные сигналы по бинарным опционам и OTC-активам. Бот прокладывает путь от регистрации на Pocket Option до выдачи сигнала, оборачивая всё дружелюбными сообщениями, кнопками и скриншотами графика.
Вы можете подключить бота и протестировать его в телеграм: @AiSignal_GPTBot

## Что делает бот
- Верифицирует пользователя через Pocket Option postback-сервер: проверяет регистрацию + депозит и предлагает пошаговые инструкции и кнопку для повторной проверки
- После активации открывает рабочую область, где пользователь выбирает пару → время экспирации → получает детальный сигнал (текст или скриншот + вероятность выигрыша + индикаторы) 
- Хранит список пользователей и одобренных заявок, а статусы Pocket Option обновляются благодаря постбэку
